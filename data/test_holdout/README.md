# The locked public test set

The user asked on the evening of 2026-11-19: besides the company's dozen or so files, also draw a few dozen of the scraped public bid tabs at random, keep them out of training, and use them purely as a test.

## What was drawn
- List: `public_holdout.csv` (version 2, md5 `9adc9f26a541de73a7b527c9e7951a42`), generated by `src/public_holdout.py --select`, random seed 20261119.
- 22% of every "year × work type (erosion/drainage, other)" cell for 2022–2026: 59 groups in all, 9 of them erosion/drainage; 34 erosion/drainage groups stay in training.
- Drawn by file: the copies of one letting (byte-identical files, and files recognised as the same letting in deduplication) are drawn together as one group: 71 files, 59 scorable lettings.
- Version 1 (half erosion/drainage) was retired before use: it took seven in ten of the erosion/drainage lettings out of training. The reason is recorded in `access_log.csv`; its list is kept as `public_holdout_v1_unused.csv`.
- The draw looked only at the bid date and the type of work, never at any estimate error.
- Locked: running `--select` again refuses to overwrite it.

## How it is kept out of training
At parse time these files are tagged `source_set = "public_test"`. The reference prices, price tables, indexes, competition discount, vocabulary, calibration constants and guards all admit only rows with `source_set == "external"`, so these lettings appear in no step of training. The last guard (`src/train_test_guard.py`) proves this cell by cell.

## How to use it
- **Only to confirm a decision registered beforehand**, never to compare options or tune parameters. Every use makes it a little "staler".
- The scoring script is `src/holdout_eval.py --confirm "<which decision is confirmed, and where it was registered>"`; every run records an entry in `access_log.csv` automatically.
- Development and self-tests may use only `--decoy` (randomly drawn decoy lettings), never the real test set.
- Registrations go in `REGISTRATIONS.md`, written before the set is opened.
