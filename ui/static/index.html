i

This tool estimates the expected low bid, as a range.

It never returns a single number. A public owner that lets bids continuously and estimates them professionally (TxDOT) still misses the eventual low bid by 13.8% median absolute error, and lands inside ±10% on only 39% of projects. A point estimate would claim precision that does not exist in this market.

Project inputs

There is deliberately no field for your OPCC. The OPCC is neither a target nor an input of this estimate — it exists only as an after-the-fact backtest baseline. Feeding it in would recycle the +51% / +22% / −35% errors the tool exists to remove.
